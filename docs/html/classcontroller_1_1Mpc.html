注解
mpc_config_path is a yaml config file, example:
  • state_dim: 2
  • input_dim: 2
  • prediction_horizon: 10
  • incremental: true
  • A: [1, 0.1, -1, -2]
  • B: [0.2, 1, 0.5, 2]
  • Q: [100, 0, 0, 100]
  • F: [100, 0, 0, 100]
  • R: [1, 0, 0, 3]

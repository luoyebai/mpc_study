详细描述

This is state transition matrix for mpc.
Transition matrix is a matrix which can be used to calculate the next state.

The state transition equation is as follows:
\( x(k+1)=\underbrace{A}_{n \times n} \underbrace{x(k)}_{n \times 1} +\underbrace{B}_{n \times p} \underbrace{u(k)}_{p \times 1} \)
